# Web UI 审查与修改计划

更新时间：2026-09-24

状态：已按确认方案实施；完整交互状态和多尺寸浏览器验收仍需补测。

## 审查范围与结论

审查现有 Web 七个页面，重点检查桌面与窄屏布局、导航可辨识度、内容层级和键盘可用性。此前在 1440px 与 320px 下检查了可进入的页面状态：桌面页面可导航且未见横向溢出；320px 下七项底部导航拥挤、标签换行或裁切，且短页面的底栏没有贴合视口底部。练习室、录音、完整报告及动画慢放等内容状态当时不可用，不能据此视为已验收。

结论：移动导航是本轮验收的阻断项。用户已确认将底部主入口精简为五项并把其余页面放入“更多”。

## 审查发现与实施方案

| 严重度 | 位置 | 发现 | 实施方案 |
| --- | --- | --- | --- |
| HIGH | `apps/web/src/App.tsx`、`apps/web/src/app.css` | 窄屏的七项底部导航标签拥挤、换行或裁切；短页面底栏停在内容下方。 | 移动端固定显示工作台、简历、准备、练习、报告和“更多”；设置、提示词管理放入可键盘操作的菜单。当前页高亮，Escape 关闭并将焦点还给触发按钮。固定底栏并为内容和安全区预留空间。 |
| MEDIUM | `apps/web/src/App.tsx`、`apps/web/src/app.css` | 跳转到主要内容链接始终显示在页面顶部。 | 保留链接和主要内容锚点，默认移出视野，键盘聚焦时显示。 |
| MEDIUM | `apps/web/src/app.css` | 面试主问题被覆盖为桌面最高 12.6px、移动端 11.2px。 | 恢复为桌面 20px、移动端 18px，行高 1.5。 |
| MEDIUM | `apps/web/src/app.css` | 只读卡片悬浮时上移并加深阴影。 | 移除通用只读卡片位移和悬浮阴影；保留交互控件的聚焦、选中和按下反馈，并将悬浮反馈限定于支持 hover 的设备。 |
| LOW | `apps/web/src/app.css` | 首页装饰波形持续循环动画。 | 移除循环动画，保留静态装饰。 |
| LOW | `apps/web/src/app.css` | 桌面导航文字与图标描边视觉重量不一致。 | 桌面导航图标描边改为 2px；移动端轻量标签图标保持 1.5px。 |

## 实施范围

- 仅修改 Web 前端与需求/UI 文档，不改服务端接口、数据模型或评分流程。
- 保留原有未提交的跳过导航链接与主要内容语义结构改动，并补齐其可见性及键盘焦点样式。
- 继续使用项目现有 React、CSS 和颜色变量。
